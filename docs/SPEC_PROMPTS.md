# Тексты для шагов Spec Kit

## Конституция
Принципы: (1) спецификация первична, код следует ей; (2) приложение не падает ни при каких сбоях источника; (3) пользователь всегда видит дату и источник данных; (4) вся логика расчёта и валидации покрыта unit-тестами и запускается одной командой; (5) десятичная арифметика через Decimal, без float для денег; (6) GUI обязателен (веб, Bootstrap 5), консольная версия не допускается; (7) git: ветка на этап, PR в main.

## Спецификация (what, без технологий)
Приложение с двумя разделами.
**Конвертер валют.** Поле суммы, выбор исходной и целевой валюты, кнопка «Конвертировать» (неактивна, пока поля пусты), результат, дата курса и источник. Источник: официальный курс НБМ (XML `https://www.bnm.md/en/official_exchange_rates?get_xml=1&date=DD.MM.YYYY`). Курс публикуется в рабочие дни. Поведение: нет сети → понятное сообщение и работа с последним сохранённым курсом с его датой; выходной/праздник (пустой ответ) → последний доступный курс с явным предупреждением; сумма отрицательная/ноль/буквы/пусто → сообщение об ошибке без конвертации; одинаковые валюты → без ошибки; последний успешный ответ хранится на диске и переживает перезапуск. Конвертация работает в обе стороны; номинал (например, 100 JPY) учитывается.
**Трекер астероидов.** Поле даты ГГГГ-ММ-ДД, кнопка получения данных, список астероидов (диаметр, скорость, расстояние до Земли, флаг потенциальной опасности `is_potentially_hazardous_asteroid`), источник «NASA API» и метка времени ответа. Пустой день/нет данных → последний успешно закэшированный день и предупреждение. Проверка формата даты и несуществующих дат (31 февраля).

## План (how)
Python 3.12, Flask, requests, Bootstrap 5.3 (CDN), чистый JS без сборки. Слои: `validation`, `currency`/`neo` (парсинг + сервис с внедряемым http), `cache` (JSON-файл, атомарная запись), `routes` (REST: `/api/rates`, `/api/convert`, `/api/neo`). Тесты: pytest для бэка, `node --test` для `logic.js`. Запуск тестов: `python run_tests.py`.
